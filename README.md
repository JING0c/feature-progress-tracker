# 功能进度跟踪

一个用于项目需求拆分、功能进度和独立验收跟踪的 Codex 技能，包含本地功能看板和项目规划对话页面。

## 启动示例

需要 Python 3。项目规划对话另需安装并登录本机 Codex 命令行。

```bash
python3 scripts/serve_dashboard.py examples/功能看板示例.md --port 8765
```

浏览器访问终端显示的本机地址；如端口被占用，程序会自动选择空闲端口。看板按大功能和多层子功能显示状态，点击卡片可以展开详情。规划页面通过本机 Codex 多轮梳理需求、依赖、优先级和验收标准，完成对话后可查看并下载项目规划书；对话保存在当前浏览器；用户可生成功能台账，审阅并确认后保存到当前台账，保存前会保留原文件备份。

示例数据是虚构的，不代表实际项目。真实项目请把上述命令中的文件替换为项目的 Markdown 功能台账。台账格式和独立审核规则见 [SKILL.md](SKILL.md)。

服务仅监听本机，不需要安装 Python 第三方依赖。浏览器中的规划对话每次会作为上下文交给本机 Codex 处理，请按实际需求选择输入的内容。
