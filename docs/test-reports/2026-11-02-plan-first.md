# 先规划流程验证

日期：2026-11-02。范围：新建与新导入项目先生成并保存项目规划书，随后才能生成功能台账、保存并查看看板。

## 实现

- 总览区分新建与导入，两种入口均进入规划页；待规划项目展示原因与开始规划，不显示看板入口和虚假的零进度。
- 规划书需具备目标、范围、功能及验收实质内容。标题、中文/英文占位模板及损坏文件不能解锁。
- 新登记项目必须走当前项目的 Codex 规划书生成及保存流程；原导入规划、普通聊天回复、跨项目/修改过的回复不能直接解锁。保存校验生成时版本并保留备份。
- 规划状态和来源保存在项目列表 Markdown；保存失败不解锁，重启后已保存状态保留；规划书被删除、清空或破坏后重新锁定。
- 页面与服务端同步限制看板地址、台账读取、生成、预览和保存；允许待规划时继续对话和读取现有资料。
- 导入参考原规划、台账及目录内 README，保留原始文件与历史。旧登记清单中已有有效规划书的项目兼容继续使用。
