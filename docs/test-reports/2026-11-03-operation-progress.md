# 规划页统一百分比阶段进度

## 覆盖与实现

统一固定面板包含操作名、百分比、当前步骤、详情、耗时、完成/失败和完成后关闭入口。规划页GitHub参考检索/选择、拆分与规划对话、建议/预览、编辑/保存、源码核对、台账预览/保存、Excel及Markdown（当前和历史）导出、历史读取、复制及文件读取均接入。简单同步视图切换不等待服务，不生成虚构耗时；项目总览未改。

后端ContextVar绑定独立请求，项目+请求ID隔离进度。Codex、GitHub、README/源码、校验写入等实际执行点上报阶段权重，不按时间虚增；不是token或克隆字节完成率。只有成功返回显示100%，失败保留步骤/比例。前端旧轮询不会覆盖新任务，短操作结束恢复仍运行的长任务。完成缓存有界回收，运行任务不会被TTL清理。
