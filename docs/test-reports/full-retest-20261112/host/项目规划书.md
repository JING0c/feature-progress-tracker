# 宿主实测-阅读清单

## 目标
用阅读清单规划验证 FPT MCP 的编辑、保存、台账和导出流程。

## 范围
规划图书记录与本地保存。本轮为隔离测试夹具，不选外部参考；真实 GitHub 及源码核对由另一独立测试负责。所有条目均未实现、未验收。
